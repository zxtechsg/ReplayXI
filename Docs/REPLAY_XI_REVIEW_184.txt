Replay XI 184 — review of pass 183 — 22 Oct 2026

Findings and fixes
- Mac zone rendering was corrected in 183, but its Frame action still used
  endpoint-box bounds. This targeted the wrong centre and cropped large circles.
  The new frame uses the whole circle, including its thickness and handles.
- The same camera action ignored viewport shape. Narrow windows clipped arcs
  and control handles. Framing now uses both horizontal and vertical field of
  view, and extends the far clip plane for large zones. Overview restores it.
- Mark rendering compared the entire wire record, including encoded edit history
  and timing. Timing-only changes rewrote native geometry despite an unchanged
  visible pose. Its checkpoint now contains only rendering inputs. Visibility,
  edit permissions, selection, labels and pose changes still invalidate it.
- The removed paged UI left 84 lines of unused layout/paging implementation
  and four obsolete tests. Removed those; retained all live tick clustering,
  metadata indexing, direct timeline and annotation editor behavior.
- The old full-window render test passed on unsupported placeholder images.
  Inspected output: ImageRenderer produced a prohibition symbol; cacheDisplay
  omitted the native 3D view and inspector. Removed these false pixel checks.
  Renamed the test to describe native window layout only. Added separate native
  SceneKit captures of the actual Frame action at wide and narrow sizes.
- Space height now uses the mean endpoint height, matching AVP rendering.
