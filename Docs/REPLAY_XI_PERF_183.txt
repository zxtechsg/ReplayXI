Replay XI 183 — bug/performance pass — 22 Oct 2026

Changes
- Cache one complete procedural-pose input per live AVP rig. Paused annotation
  and HUD updates skip duplicate motion evaluation and joint writes. Checkpoints
  are bounded by the existing 32-binding cap and removed with detached rigs.
- Invalidate the checkpoint after an impact blend: repeated paused impacts must
  rebuild the base pose, not accumulate a blend over the previous result.
- Mac allocates geometry only for visible or selected annotations. Hidden history
  owns no SceneKit nodes; reverse seeks rebuild from the current received pose.
- Straight Mac marks use one path segment instead of 32 (96.875% fewer path
  segments, not a measured total-memory or GPU-time reduction). Arcs retain all
  32 segments. Zones and player labels allocate no path segments.
- Mac skips unchanged player-property writes and refreshes number/team metadata
  when a study reuses a player ID. Previously those fields stayed stale.
- Fix Mac 2D and 3D space marks: start is the centre, end defines a circular
  radius, minimum 1.1 m, matching the AVP renderer. Previously Mac used opposite
  bounding-box corners and displayed an offset ellipse.
- Remove 391 lines of unreachable paged-timeline and old annotation controls.
  Replace obsolete source checks with checks of the active track/editor routes.
  Keep movement, key-capacity, timing, close and gesture-ownership coverage.
- Put the hidden-mark guidance in the actual track list, where it can be seen.

Measured scope
- Debug visionOS 26.5 Simulator; PitchSceneFactory.update CPU only, no renderer.
- Five native-ball reference studies, three views, forward/reverse/paused.
- Lightweight rendering: four-skin budget, with procedural background players.
- Mean of the 15 per-case median update times:
                    Before       After
  Forward           3.381 ms     3.399 ms
  Reverse           3.385 ms     3.409 ms
  Paused            1.814 ms     0.465 ms   (74.4% lower)
- Across 900 paused updates: zero procedural-pose evaluations, 16,500 cache hits.
- Active CPU cost was about unchanged in this single before/after run. These are
  unpaced CPU diagnostics, not FPS, battery/power measurements or device results.
- The default Full squad setting, 60 Hz playback cadence, mesh quality, player
  tracks, native contacts, animation and existing skin admission caps are unchanged.
- Both detail choices passed the existing 20-case squad/resource/rewind diagnostic.
  The 74.4% figure does not describe Full squad or overall app CPU.
